Learning is influenced by prior knowledge, maturity, motivation, emotions and settings such as home and school. A learning curve plots performance across practice and can include a plateau. Retrieval practice and spaced review strengthen access to knowledge. Interference occurs when earlier or later learning competes with recall. Transfer is positive when prior learning helps a new task and negative when an old response interferes.

## Worked example

Students learn that area counts square units and then apply the idea to an unfamiliar tiled floor. This is positive transfer across examples.

## Common mistake

Repeated reading can feel fluent without producing durable recall. Check whether a learner can retrieve and apply the idea independently.

## Practice

How can you tell a learner has transferred a concept?

**Answer:** Give a new problem with different surface features and check whether the learner applies the underlying principle correctly.

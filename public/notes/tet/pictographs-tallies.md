Tallies count occurrences, often in groups of five. Pictographs use a key that maps an icon to a quantity. Bar graphs compare category counts, double bars compare two series and pies compare shares of a whole. Title, labels and a consistent scale make each readable.

## Worked example

A pictograph says one symbol represents eight pupils. Three symbols and half a symbol represent 3.5×8=28 pupils.

## Common mistake

Read the key before counting icons. One icon can represent several observations.

## Practice

Which display helps compare attendance at two schools on each weekday?

**Answer:** A double bar graph, with both schools' counts shown side by side for each day.

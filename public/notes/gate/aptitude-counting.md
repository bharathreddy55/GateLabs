Use the product rule for sequential choices. Ordering r distinct items from n gives nPr=n!/(n−r)!. Choosing an unordered set gives nCr=n!/(r!(n−r)!). Repeated symbols reduce the number of distinct orderings by corresponding factorials.

## Concepts in depth

Permutations count ordered arrangements. Combinations count unordered selections. For constraints use blocks, complementary counting, or cases. If repetitions are identical, divide labelled arrangements by factorials of multiplicities where every arrangement has the same overcount.

## How to apply it

Five distinct people in a line with A and B consecutive give 2×4!=48 arrangements because the pair has two orders. If asked where they sit in a circle with rotations treated as the same, fix one reference before counting.

## Worked example

Choose a president and secretary from five people: 5×4=20. Choose a two-person committee from five: 20/2=10.

## Common mistake

Decide whether order matters before selecting a formula.

## Practice

How many distinct arrangements of LEVEL exist?

**Answer:** 30, from 5!/(2!2!) because L and E each repeat twice.

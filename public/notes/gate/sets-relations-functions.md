A relation from A to B is a subset of A×B. Equivalence relations are reflexive, symmetric and transitive and partition their domain. A function assigns each input exactly one output. Injective functions distinguish inputs, surjective functions reach all of their codomain, and bijections do both. Use function composition in the order f(g(x)).

## Concepts in depth

A relation on A is a subset of A×A. Equivalence is reflexive, symmetric and transitive and partitions A into classes. A function assigns one output per input. Injective means distinct inputs have distinct outputs, while surjective means each codomain element is hit.

## How to apply it

On integers, same remainder modulo 3 forms three equivalence classes. A map x→x² from integers to nonnegative integers is neither injective nor onto. Changing its domain and codomain can change these properties.

## Worked example

On integers, relation aRb when a−b is divisible by 3 is an equivalence relation. Its three classes are the three possible remainders.

## Common mistake

Range consists of attained values. The declared codomain can contain values the function does not reach.

## Practice

Is f(n)=2n a bijection from integers to integers?

**Answer:** No. It is injective but misses all odd integers.

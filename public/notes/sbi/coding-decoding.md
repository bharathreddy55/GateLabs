Test letter substitution, shifts, reversal, position values and changes by character index. Derive the transformation from complete examples before applying it. With word-code matching, use the overlap between two sentences to isolate a shared token.

## Worked example

If RED becomes SFE, each letter advances one position. BLUE becomes CMVF by applying the same shift.

## Common mistake

The observed mapping may be positional. Check multiple letters before treating it as one uniform shift.

## Practice

If MAP becomes PAM by reversal, what does LAMP become?

**Answer:** PMAL. Read the original characters from last to first.

Turn a prose caselet into a table and mark what each number measures. Compute obvious complement values only when the categories exhaust the same total. Carry the reference base through percentage comparisons.

## Worked example

A branch handles 210 transactions, 40% online. If every transaction is online or offline, offline count = 210×0.60=126.

## Common mistake

Two groups can overlap. Do not force a complement without checking the stated relationship.

## Practice

An office has 40 loans approved out of 50 applications. What is its approval rate?

**Answer:** 80%, using applications as the denominator.

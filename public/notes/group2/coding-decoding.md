## Concepts in depth

Use examples to isolate substitutions, position-dependent shifts, reversals or permutations. If unrelated examples share one word, compare the overlapping code. For mixed operations, write each intermediate state. To decode, undo operations in reverse order.

## How to apply it

If TRAIN is reversed and then each letter advanced once, reverse first to NIART and encode OJBSU. Decode by shifting each letter back before reversing. Check examples for wraparound and for different shifts in odd and even positions.

## Worked example

If RED becomes SFE, each letter advances one position. BLUE becomes CMVF by applying the same shift.

## Common mistake

The observed mapping may be positional. Check multiple letters before treating it as one uniform shift.

## Practice

**Answer:** PMAL. Read the original characters from last to first.

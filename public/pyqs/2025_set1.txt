Subject: Engineering Mathematics
Subtopic: Probability / Bayes' Theorem
Difficulty: Medium
Marks: 2
Year: 2025
Question: A box contains 5 coins: 4 regular coins and 1 fake coin. When a regular coin is tossed, the probability P(head) = 0.5 and for a fake coin, P(head) = 1. You pick a coin at random and toss it twice, and get two heads. The probability that the coin you have chosen is the fake coin is:
Option A: 0.20
Option B: 0.50
Option C: 0.25
Option D: 0.80
Correct: B
Explanation: Let F be fake and R be regular. P(F)=1/5, P(R)=4/5. P(2H|F) = 1, P(2H|R) = 0.25. By Bayes' theorem, P(F|2H) = P(2H|F)P(F) / [P(2H|F)P(F) + P(2H|R)P(R)] = (1 * 0.2) / (1 * 0.2 + 0.25 * 0.8) = 0.2 / 0.4 = 0.50.

Question: A 512MB disk has 64KB blocks. Linked allocation is used where each block reserves 4 bytes for the next pointer (NULL for last block). The space in bytes wasted due to internal fragmentation for a 1MB file is:
Option A: 65468
Option B: 65532
Option C: 64
Option D: 0
Correct: A
Explanation: Block size = 65536 bytes. Usable space per block = 65536 - 4 = 65532 bytes. File size = 1M = 1,048,576 bytes. Number of blocks = ceil(1,048,576 / 65,532) = 17 blocks.
